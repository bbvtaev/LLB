# LLB: Learning Language Bot

Личный Telegram-бот для заучивания слов на любом языке с интервальным повторением.

```
USER ⇄ TG BOT (Go) ⇄ POSTGRES
```

## Запуск

```sh
cp .env.example .env   # заполнить TG_TOKEN и POSTGRES_PASSWORD
docker compose up -d --build
```

При первом старте оставь `OWNER_ID` пустым и напиши боту: он ответит твоим id. Впиши id в `.env` и выполни `docker compose up -d`.
Миграции из [migrations/](migrations/) применяются автоматически при старте бота.

## Деплой на сервер

```sh
./scripts/deploy.sh root@<ip-сервера>
```

Скрипт копирует код в `~/llb`, делает бэкап базы в `~/llb-backups` и пересобирает бота. База живёт в Docker volume `llb_pgdata`, деплой её не трогает.
**Никогда не запускай `docker compose down -v`**: флаг `-v` удаляет базу.

Восстановить базу из бэкапа:

```sh
gunzip -c ~/llb-backups/<файл>.sql.gz | docker compose exec -T db psql -U llb llb
```

## Как пользоваться

- **Добавить слово:** просто отправь `apple - яблоко | заметка #группа1 #группа2`. Можно несколько строк за раз. Разделитель: ` - `, ` — `, `=` или таб.
- **/review:** выбрать, что повторять: ⏰ только слова с истёкшим таймером или 📚 все подряд. Можно по всем словам сразу или по отдельной группе.
- **Карточка:** перевод спрятан под спойлером. Можно напечатать ответ (бот его проверит) и оценить:
  - 🔁 repeat: через 1 минуту
  - 👍 good: через 1 день
  - 🚀 fluent: через 3 дня, потом 6, 12 и дальше до 192 (если fluent несколько раз подряд)
- **/lang ja** переключает язык, **/dir** переключает направление (слово → перевод, наоборот, вперемешку).
- **/list [#группа]**, **/stats**, **/del слово**, **/stop**.
- Напоминания приходят в `REMIND_AT` (по умолчанию 10:00 и 20:00), если есть слова к повторению.

## Залить слова миграцией

Создай следующий по номеру файл в `migrations/`, например `00002_words_food.sql`:

```sql
-- +goose Up
SELECT add_word('en', 'apple',  'яблоко', 'an apple a day', ARRAY['еда']);
SELECT add_word('en', 'bread',  'хлеб',   NULL,             ARRAY['еда', 'базовые']);
SELECT add_word('ja', '猫',      'кошка',  'ねこ',            ARRAY['животные']);

-- +goose Down
```

`add_word` обновляет перевод, если такое слово уже есть, и не трогает прогресс. После этого выполни `docker compose up -d --build`.
